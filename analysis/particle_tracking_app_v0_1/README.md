# Experiment Manager v0.5

The directory name is retained for import compatibility. Start from the
repository root with `python run_experiment_manager.py`. See the root README
for installation, calibration, workflow, compatibility and limitations.

This release removes historical calibration defaults, starts with an empty
local catalog and uses the existing `models/best.pt`. Source hashes are in
`docs/manager-v0.5-source-manifest.json`.
